# 虛擬教學案例：設計接案合約審核

一組完整的課堂示範素材，對應課程「怎麼開始做 AI Skills」單元。所有公司、人名、統編皆為虛構。

| 檔案 | 內容 |
|---|---|
| `quote-v1.md` | 設計接案報價單（內含 2 個問題） |
| `contract-v1.md` | 合約初版，大致公平，當「合理基準」（與報價單有 2 處落差） |
| `contract-v2-client-revised.md` | 客戶宣稱「只調整用字」的回傳版（8 處悄悄改動） |
| `ANSWER-KEY.md` | 講師用陷阱解答與課堂示範流程（共 12 個問題） |

建議示範順序：`/review` 初版 → 報價單一致性檢查 → `/compare` 兩版抓悄悄改動。
